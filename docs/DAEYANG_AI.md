# 대양AI센터 모델

`npm.cmd run dev` 후 `/models/?model=daeyang-ai`에서 독립 미리보기를 연다. 기존 `/models/`에는 애지헌·대양타워가 유지되며 상단 링크로 두 모델을 선택한다. 전체·정면·옥상 시점, 회전·확대·이동 및 자동 회전을 지원한다.

모델은 `client/host/models/daeyangAi.ts`의 `createDaeyangAi()`에서 생성한다. 브라우저 Canvas로 유리창 격자와 간판 텍스처를 만들며 외부 이미지나 새 패키지를 사용하지 않는다. 원점은 바닥 중심, +Y는 위, +Z는 정면이다.

## 게임 배치

- 애지헌과 같은 규칙으로 무한 도로에 섞인다. `world.landmarkFirstChunk`(2)부터 `world.landmarkEveryChunks`(4) 간격으로 두 랜드마크가 번갈아 나오므로 대양AI센터는 약 480m마다, 애지헌과 반대 배치 순서로 등장한다. 정면은 항상 도로를 향한다.
- `world.landmarkScale['daeyang-ai']: 1.25`로 키워 배치한다. 모델 높이 54.9m가 68.6m, 바닥 48×42m가 60×52.5m가 된다. 1.25가 상한이다. 바닥 폭 48m × 배율이 구간 길이 60m를 넘으면 이웃 구간까지 넘어가 구간 단위 회수와 어긋난다. 더 키우려면 구간 길이부터 바꿔야 한다.
- 저층부·상층부·옥상 난간을 구분한 상자 충돌체로 충돌·거미줄 판정을 연결했다. 유리 격자, 기둥 굴곡, 테라스 세부는 단순화한 판정이다.
- 모델의 바닥 경계와 겹치는 같은 쪽 일반 건물은 제거한다. 구간 번호로 배치가 정해져 재시작·재생성 시 동일하다.
- geometry·material·texture는 한 번 만들고 구간 사이에서 공유하며, 구간 회수 시 복제한 Group과 해당 구간 충돌체만 제거한다.

## 사진과 추정 범위

사용자 제공 `21102_11540_1538.jpg` 실물 사진을 입면의 우선 기준으로 삼았고 `images.jpg` 조감도를 옥상 테라스 참고 자료로 사용했다. 넓은 저층부, 좁아지는 상층부, 청록색 세로창, 석재 기둥과 수평 띠, SEJONG 간판을 표현했다. 조감도가 준공 상태와 동일하다는 의미는 아니다.

실제 치수·층수·창문 수를 측정하지 않았다. 가려진 면, 출입구, 옥상 설비와 테라스 난간은 단순화한 추정이다. SEJONG 옆 엠블럼은 사진의 세부 판독이 어려워 원형 S 표식으로 대체했으며 공식 로고 재현이 아니다. 주변 건물·차량·수목은 포함하지 않았다.

## 확인 (2026-09-16)

Windows 로컬, Node.js v24.19.0, localhost 개발 서버, Playwright 기본 Chromium 조건에서 타입 검사와 빌드를 통과했다. 1440×1000 전체·옥상 화면과 390×844 전체 화면을 캡처해 시각 확인했다. 시점 버튼·자동 회전 토글 및 애지헌 미리보기 복귀를 실행했고 브라우저 pageerror는 없었다. 빌드에는 기존 500kB 초과 청크 경고가 남는다. 실제 휴대폰 터치와 전시장 PC 성능, 장시간 실행은 미검증이다.
