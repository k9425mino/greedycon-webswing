# 애지헌 독립 모델 미리보기

`npm.cmd run dev` 실행 후 `http://localhost:5173/models/`에 접속한다. 빌드 후 `npm.cmd run start`로 실행해도 같은 경로를 사용한다.

- 드래그: 회전, 휠: 확대/축소, 오른쪽 드래그: 이동.
- 전체·정면·예배당 시점 버튼, 자동 회전 토글 제공.
- 모델: `client/host/models/aejiheon.ts`의 `createAejiheon()`이 Three.js Group을 반환한다. 브라우저에서 호출하며 석재·지붕 텍스처를 Canvas로 생성한다. 외부 이미지 다운로드나 새 패키지가 필요 없다.
- 원점은 탑 바닥 중심, +Y는 위, +Z는 정면. `Daeyang Tower`와 `Aejiheon Chapel` 하위 그룹으로 구성된다.
- 독립 미리보기와 게임 월드에서 같은 모델을 사용한다.

## 게임 배치

- `shared/config.ts`의 `world.landmarkFirstChunk: 2`, `landmarkEveryChunks: 4`로 첫 120~180m 구간부터 약 240m마다 랜드마크를 놓는다. 애지헌과 대양AI센터가 번갈아 나오므로 애지헌은 약 480m 간격이다. 간격은 제안 초기값이며 체감 튜닝 전이다.
- 탑 정면은 항상 도로 쪽을 향하고 예배당은 도로 바깥에 놓인다.
- `world.landmarkScale.aejiheon: 1.6`으로 키워 배치한다. 모델 높이 55.1m가 88.2m가 돼 일반 건물 범위(45~70m)보다 확실히 높고, 탑 몸통 폭도 8m에서 12.8m가 된다. 1.25로는 주변 건물에 묻혀 작아 보인다는 지적이 있었다. 자동 캡처로 확인한 값이며 실제 플레이 체감은 미검증이다.
- 모델의 바닥 경계와 겹치는 같은 쪽 일반 건물만 제거한다. 구간 번호로 배치가 결정되므로 재시작·재생성 시 동일하다.
- 탑과 예배당 높이를 구분한 상자 충돌체로 충돌·거미줄 판정을 연결했다. 아치 구멍, 몰딩, 지붕 경사는 단순화된 판정이다.
- 모델 geometry·material·texture는 한 번 만들고 복제한 Group끼리 공유한다. 구간 회수 시 Group과 해당 구간의 충돌체를 제거하고 공유 모델 자원은 유지한다.
- 탑 꼭대기 지붕 장식(모델 좌표 y 50.4~54.0)만 바닥 경계 바깥으로 최대 3.3m(배율 1.6에서 5.3m) 나와 도로 위에 걸친다. 충돌체는 이 돌출을 포함하지 않아 그 부분은 통과한다. 높이 80m 위쪽이라 평소 스윙 경로와는 떨어져 있지만 확인된 시각·판정 불일치다.

## 재현 범위

사용자가 제공한 `981938537604e.jpg`, `2630_1_cd50ad5db9679844845d60cd4599c96b.jpg` 두 사진을 참고했다. 앞쪽 대양타워와 뒤쪽 애지헌 예배당을 함께 표현한다. 석재 외벽, 수평 몰딩, 상단 삼연 아치, 원형 문양, 금빛 피라미드 지붕, 예배당 박공지붕·아치창을 모델링했다.

실측 모델이 아니다. 높이·폭·간격은 사진 기반 추정이며 가려진 뒷면, 출입구, 창문 수와 배치는 단순화했다. 탑 원형 문양과 스테인드글라스는 판독 가능한 세부 자료가 없어 기하학적 장식으로 대체했다. 주변 도로·수목·차량과 다른 캠퍼스 건물은 포함하지 않는다. 원본 사진을 텍스처로 복제하지 않았다.

## 검증 (2026-09-16)

Windows 로컬, Node.js v24.19.0, Playwright 기본 Chromium, localhost 개발 서버에서 확인했다.

- `npm.cmd run typecheck`, `npm.cmd run build` 통과. 빌드에는 500kB 초과 청크 경고가 남는다.
- 1440×1000 및 390×844 화면을 렌더링해 캡처를 시각 확인했다.
- 전체·정면·예배당 버튼, 자동 회전 토글, 드래그·휠 입력 실행 중 브라우저 `pageerror` 없음.
- 실제 폰 터치 조작, 전시장 PC 성능, FPS와 장시간 실행은 검증하지 않았다.

게임 배치 추가 후 같은 Windows·Node.js·로컬 Chromium 조건에서 타입 검사·빌드, 단위 테스트 136개, `mouseSwing.spec.ts`의 마우스 플레이 테스트 5개가 통과했다. 단위 테스트로 좌우 방향·도로 및 일반 건물 비침범·구간 경계·자원 공유·탑 조준·예배당 위 빈 공간·충돌체 회수·500m 스트리밍을 확인했다. 1440×900 화면에서 실제 게임 초기 화면과 게임의 월드·렌더 모듈로 생성한 좌우 랜드마크 근접 화면을 캡처해 시각 확인했으며 브라우저 `pageerror`는 없었다. 실제 폰 플레이와 장시간 성능은 미검증이다.
